# 02 — Idea Bank

Concept menu for ideation. Each idea = a hook archetype + a topic from the saved set + a build/teach angle, mapped to the 5 beats. Because your pipeline starts from a blog, each idea is framed as a **blog/YouTube topic** that then compresses into clips, carousels, and Remotion reels.

Format per idea: **Hook → Problem → Reveal+proof → Payoff → CTA keyword**.

## Tier 1 — Build-in-public reveals (trust engine, closest to the winner)

1. **"I automated the worst part of ___"** (emails / invoicing / standups)
   Problem: a daily grind everyone feels → Reveal: screen-record the tool running, free/open/local → Payoff: time saved → CTA: **BUILD**.
2. **"Claude as your computer" — agent does a real task end to end**
   → screen-record a multi-step task → CTA: **AGENT**.
3. **"Claude Code + MCP — the upgrade most people never turn on"**
   → before/after of the same task with an MCP connected → CTA: **MCP**.
4. **"I stopped paying for AI subscriptions — the local setup"**
   → terminal/desktop B-roll running offline (do this one HONESTLY — see guardrail, the hyped version got roasted) → CTA: **LOCAL**.

## Tier 2 — Teach (reach engine; carousel + screen-record native)

5. **"10 ways to cut your Claude token bill 75%"** — listicle/carousel → CTA: **TOKENS**.
6. **"4 things Claude can do that'll make you feel dumb for not using sooner"** — 4 quick demos → CTA: **CLAUDE**.
7. **"Stop prompting. Do this instead."** — set-up-before-you-prompt workflow → CTA: **SETUP**.
8. **"If I had one weekend to master Claude, I'd start here"** — roadmap carousel / blog pillar + lead magnet → CTA: **WEEKEND**.
9. **"I built a live dashboard in 4 minutes with Claude"** (Excel / interactive charts) → screen-record the build → CTA: **EXCEL**.
10. **"Connect Claude to [your social tool] via MCP"** — the top-performing pattern in the data → CTA: **CONNECT**.

## Tier 3 — Curiosity (top-of-funnel, sparing)

11. **"I tried the Reddit prompt that 'gaslit' Claude — what really happened"** — debunk the hype, show the real result → CTA: **PROMPT**.
12. **"FREE vs PAID AI tools — what I actually use"** — split-screen carousel of your real stack → CTA: **STACK**.

## Using the bank in a blog-first flow
- Pick an idea → it becomes the **blog post angle** (use the matching hook archetype for the title).
- The blog's strongest 30–45s argument becomes the **reel/clip hook + 5 beats**.
- Listicle/roadmap ideas (5, 8, 12) should *also* spawn a **carousel + worksheet** in the social step.
- Tier 1 ideas need real B-roll captured during the build — flag at blog-draft time so you film it.
