# @mavgpt Caption Formula (DS / build-in-public reels)

## Reference account: @mavgpt (Maverick Maltin — AI & ChatGPT), 887k followers

Reels analyzed: 3.8m, 1.3m, 1.1m, 168k, 130k, 116k, 104k, 72.2k, 56.6k, 51.8k views.

## The core insight: the caption IS the product

The reel stops the scroll; **the caption is what people screenshot and save.** Full value
(prompts, steps, the list) lives in the caption body — not just behind a DM keyword. The DM
sends a formatted copy; the caption already contains it.

## Caption structure (mandatory order)

```
Line 1:  Comment "[KEYWORD]" and I'll send you [specific deliverable] 👆
Line 2:  [One-line proof/claim — specific, verifiable-sounding]
Line 3+: [Numbered list — the full value verbatim, immediately actionable]
Last:    #hashtag1 #hashtag2 #hashtag3 #hashtag4 #hashtag5
```

Real examples:
- 3.8m — "Comment 'Jobs' and I'll send you all the prompts 👆 / What happens when you ask ChatGPT
  to apply to 500 jobs? / I tried this and landed 12 interviews in 24 hours. / Prompt 1: … / Prompt 2: …"
- 1.1m — "Comment 'AI' and I'll send you my 2026 AI stack 👆 / The best AI for every task right now.
  / Writing emails: Claude / Brainstorming: ChatGPT / …"
- 104k — "Comment 'Settings' and I'll send you my full list 👆 / 5 hidden ChatGPT settings most
  people never turn on. / 1. Memory → Personalization → … / …"

## Thumbnail text formula — state the OUTCOME, not the topic

| Works | Doesn't work |
|-------|--------------|
| "ChatGPT applied to 500 jobs for me 😳" | "How to use ChatGPT for job hunting" |
| "5 Secret Settings for ChatGPT 🤯" | "ChatGPT tips" |
| "Claude just killed personal trainers 🤯" | "Claude for fitness" |

Patterns: `[N] [secret/hidden] X for [tool] 🤯` · `[tool] just [killed/replaced/changed] [Y] 🤯`
· `[I/tool] [dramatic thing] to [specific outcome] 😳`.

## Serialization

Number the series ("pt1", "pt2"…) — builds returning viewers + algorithmic advantage. Name the
series in the thumbnail from pt1 (e.g. "Prompt Anatomy pt1", "DS Tools pt1").

## Tarun's DS adaptation (voice + guardrails)

- The 5-part prompt template belongs IN the caption (DM sends a formatted version too).
- Frame from expertise ("I've reviewed / I teach"), never personal ignorance ("until last week").
- Caption value must be **universally applicable**, not situation-specific.
- Honesty guardrail: state what the tool/template actually does; never overclaim.
- Banned words: "In conclusion / Dive into / Leverage / Game-changer / Synergy".
- Hashtags: DS-focused, max 5 — `#datascience #ai #chatgpt #python #dataanalyst`.
