Re-sync Procedure

Governance loop for keeping this mirror truthful.

When a source changes → affected cards

Source fileCards to re-sync

Steps

1. python3 v1/scripts/generate_design_system.py
2. git diff --name-only v1/design-system/   # changed files only
3. /design-sync — finalize_plan + write_files for changed paths
   (deletes for removed files; never wholesale replace)
