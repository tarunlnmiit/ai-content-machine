# D2 — "Load-Bearing Type" — LOCKED TEMPLATE PACK

Typography-first editorial. There is no image, no gradient, no card — the sentence IS the page,
set at a scale most designers are too timid to attempt on a phone screen. This is what a
magazine's pull-quote spread looks like with the magazine deleted and only the quote kept.
Coral is rationed to a single load-bearing mark per slide so it reads as an edit, never decoration.

## Visual language

- **Palette**: near-monochrome — cream `#F7F2EA`, ink `#1E1B2E` doing 90% of the work. Coral
  `#E8705A` appears once per slide (a rule, an underline, one recolored word). Muted `#9A9184` for
  structural labels; `#B34A38` for the eyebrow label only; hairline `#DED5C4`.
- **Fonts**: Lora 700 at enormous scale (46-70px), tight leading, **authored** line breaks — the
  browser never reflows this, every break is chosen to land on the sentence's real pause. Nunito
  Sans 700/800/900, small, uppercase, wide-tracked, for every structural label (count, brand,
  eyebrow, footer).
- **Ground**: always flat cream. No photo, no texture, no collage card. The confidence of the type
  scale is the entire visual system — do not add a background image or gradient to "help" a slide.

## How these templates work (read before generating)

1. Every template below ships as a complete markup block + the CSS it needs. Use it EXACTLY — only
   fill the `<!-- SLOT: ... -->` comments with real copy, and always author the headline's `<br>`
   line breaks yourself (never let the browser wrap it).
2. Coral spends itself exactly once per slide: the rule under the headline, OR a single recolored
   word inside the headline, OR the underline on the CTA button — never more than one coral
   instance on any given slide.
3. Two typefaces, two jobs, never blurred: Lora carries the emotional headline; Nunito Sans carries
   only structural labels. Never set body prose in Nunito Sans at reading size, and never set a
   structural label in Lora.
4. The scale contrast (90px+ headline vs. 10px caption) IS the hierarchy system. Do not add boxes,
   pills, or badges to mark importance — size already told the reader what matters.
5. A headline may run 1-4 lines depending on the sentence's real length — never compress a long
   line to fit, shrink font-size in a fixed small step instead (see Rules).

## Chrome mapping (contract elements re-skinned natively)

There is no HUD here — every required overlay element is folded into the type system's own top
row and footer band, never a floating pill:

- `.progress-row` / `.progress-seg` / `.fill` → a thin tick row of tiny coral ticks sitting directly
  under the top count/brand row (the one place this system allows more than one coral mark, since
  it reads as a ruler, not decoration).
- `.counter-chip` → the existing top-left count mark (small coral square + "01 / 09").
- `.follow-tag` → **CTA slide only.** Replaces the top-right brand label's text with "Tap to follow
  →", same tiny uppercase treatment, now colored coral instead of muted gray — the one slide where
  the brand mark itself becomes the ask.
- `.save-tag` → **Hook slide only.** A second tiny uppercase label mirrored under the footer's
  `.next` line, muted gray, reading "Save this ↓".
- `.cliffhanger` → the existing footer `.next` line already IS the teaser copy; add the class
  there directly.
- swipe arrow → the existing footer `.arrow` circle; add `class="swipe-arrow"` to it.

```css
.progress-row{position:absolute;top:54px;left:30px;right:30px;display:flex;gap:4px;z-index:20;}
.progress-seg{flex:1;height:2px;border-radius:1px;background:rgba(30,27,46,.1);overflow:hidden;}
.progress-seg .fill{height:100%;background:#E8705A;}
.follow-tag{font-weight:800;font-size:9.5px;letter-spacing:.14em;color:#E8705A;text-transform:uppercase;}
.save-tag{font-weight:700;font-size:9px;letter-spacing:.05em;color:#9A9184;text-transform:uppercase;margin-top:4px;}
```

## HOOK TEMPLATE (mandatory) — Authored Headline

```html
<div class="frame">
  <div class="top">
    <div class="count"><span class="sq"></span><span class="counter-chip"><!-- SLOT: e.g. "01 / 09" --></span></div>
    <div class="brand">Breath of Life</div>
  </div>
  <div class="progress-row"><!-- one .progress-seg per slide in the deck --></div>
  <div class="mid">
    <div class="eyebrow"><!-- SLOT: short uppercase eyebrow --></div>
    <div class="headline"><!-- SLOT: hook headline, 5-8 words, author the &lt;br&gt; breaks yourself --></div>
    <div class="rule"></div>
  </div>
  <div class="foot">
    <div class="cliffhanger next"><!-- SLOT: "Next — ..." teaser --></div>
    <div class="arrow swipe-arrow">&rarr;</div>
  </div>
</div>
```

```css
*{margin:0;padding:0;box-sizing:border-box;-webkit-font-smoothing:antialiased;}
html,body{width:420px;height:525px;overflow:hidden;background:#F7F2EA;}
.frame{width:420px;height:525px;position:relative;display:flex;flex-direction:column;font-family:'Nunito Sans',sans-serif;padding:26px 30px 22px;}
.top{display:flex;justify-content:space-between;align-items:center;}
.count{display:flex;align-items:center;gap:6px;font-weight:800;font-size:11px;letter-spacing:.04em;color:#1E1B2E;}
.count .sq{width:7px;height:7px;background:#E8705A;display:inline-block;}
.brand{font-weight:800;font-size:9.5px;letter-spacing:.14em;color:#9A9184;text-transform:uppercase;}
.mid{flex:1;display:flex;flex-direction:column;justify-content:center;}
.eyebrow{font-weight:800;font-size:11.5px;letter-spacing:.1em;color:#B34A38;text-transform:uppercase;margin-bottom:16px;}
.headline{font-family:'Lora',serif;font-weight:700;font-size:60px;line-height:1.04;color:#1E1B2E;letter-spacing:-.01em;}
.rule{display:block;height:5px;width:96px;background:#E8705A;margin-top:20px;}
.foot{border-top:1px solid #DED5C4;padding-top:14px;display:flex;justify-content:space-between;align-items:center;}
.next{font-weight:700;font-size:9.5px;letter-spacing:.03em;color:#9A9184;max-width:290px;line-height:1.3;text-transform:uppercase;}
.arrow{width:22px;height:22px;border-radius:50%;background:#1E1B2E;color:#F7F2EA;display:flex;align-items:center;justify-content:center;font-size:12px;flex-shrink:0;}
```

Do not shrink the headline scale or add a supporting image — the oversized, unhedged type IS the
whole design; a smaller or "safer" headline is a failed execution of this archetype.

## CTA TEMPLATE (derived from hook)

```html
<div class="frame">
  <div class="top">
    <div class="count"><span class="sq"></span><span class="counter-chip"><!-- SLOT: e.g. "09 / 09" --></span></div>
    <div class="follow-tag">Tap to follow &rarr;</div>
  </div>
  <div class="progress-row"><!-- full deck, all filled --></div>
  <div class="mid mid-cta">
    <div class="eyebrow"><!-- SLOT: recap eyebrow --></div>
    <div class="headline headline-cta"><!-- SLOT: CTA line, authored breaks, matches hook's promise --></div>
    <div class="rule"></div>
    <div class="cta-btn"><!-- SLOT: comment-keyword CTA copy --></div>
  </div>
</div>
```

```css
.headline-cta{font-size:44px;}
.cta-btn{margin-top:26px;background:#1E1B2E;color:#F7F2EA;font-family:'Nunito Sans',sans-serif;font-weight:800;font-size:14px;text-align:center;padding:14px;border-radius:4px;letter-spacing:.02em;}
```

The CTA button is the ONE place this system permits a filled block rather than a rule or a word —
it is the single coral-adjacent "spend" reserved for the final ask, styled ink-on-cream to match
the headline's own contrast rather than introducing a new color.

## BODY TEMPLATES

### Lede + Headline (mockup body — small italic setup line above the big payoff line; the default
body template for a reframe/realization beat)

```html
<div class="mid">
  <div class="eyebrow"><!-- SLOT: topic eyebrow --></div>
  <div class="lead"><!-- SLOT: short Lora italic setup line, e.g. "Before I answer anything, I ask myself&mdash;" --></div>
  <div class="headline"><!-- SLOT: payoff headline, authored breaks --></div>
  <div class="rule"></div>
</div>
```

```css
.lead{font-family:'Lora',serif;font-style:italic;font-weight:500;font-size:19px;line-height:1.35;color:#5B5548;margin-bottom:14px;}
.headline{font-size:46px;}
```

### Numbered Reframe (for list/practice content — a ghost numeral anchors the headline)

```html
<div class="mid">
  <div class="num-row"><span class="ghost-num"><!-- SLOT: e.g. "01" --></span></div>
  <div class="headline"><!-- SLOT: the practice/step line, authored breaks --></div>
  <div class="rule"></div>
</div>
```

```css
.num-row{margin-bottom:6px;}
.ghost-num{font-family:'Lora',serif;font-weight:700;font-size:22px;color:#DED5C4;letter-spacing:-.01em;}
.headline{font-size:44px;}
```

### Two-Line Contrast (for a "not X — but Y" reframe beat — small muted setup, huge underlined
payoff)

```html
<div class="mid">
  <div class="contrast-a"><!-- SLOT: the thing being reframed away from, small, muted --></div>
  <div class="headline"><!-- SLOT: the reframe payoff line, one word wrapped in &lt;span class="u"&gt; for the coral spend --></div>
</div>
```

```css
.contrast-a{font-family:'Nunito Sans',sans-serif;font-weight:700;font-size:13px;color:#9A9184;text-decoration:line-through;text-decoration-color:#DED5C4;margin-bottom:12px;}
.headline{font-size:50px;}
.u{border-bottom:5px solid #E8705A;padding-bottom:2px;}
```

Note: when `.u` is used, the standalone `.rule` element is dropped entirely — this slide's single
coral spend is the underline, not a separate rule.

### Full-Bleed Statement (no eyebrow — for the single most quotable line in the deck; type alone,
edge to edge)

```html
<div class="mid mid-bleed">
  <div class="headline headline-bleed"><!-- SLOT: the one standalone sentence, authored breaks --></div>
</div>
```

```css
.mid-bleed{padding:0 4px;}
.headline-bleed{font-size:52px;line-height:1.08;}
```

No eyebrow, no rule, no footer teaser competing for attention — this template still keeps the top
count/brand row and bottom footer band, but the middle zone holds nothing but the sentence.

## Rules

- One coral instance per slide, never zero on the hook/body/CTA (Full-Bleed Statement is the only
  template allowed to drop the rule entirely, and only because it has no room for one).
- Headline line breaks are always authored (`<br>`), never left to the browser to reflow.
- Nunito Sans never appears at reading size in a headline position; Lora never appears in a
  structural label.
- Eyebrow always precedes the headline when present; footer band (hairline + next + arrow) is
  present on every slide except the CTA slide, which trades it for the button.
- Body copy under 30 words per slide; hook headline 5-8 words hard cap.
