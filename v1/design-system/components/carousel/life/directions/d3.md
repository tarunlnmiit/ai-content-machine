# D3 — "After Hours" — LOCKED TEMPLATE PACK

Quiet dark luxury. The office after everyone else has gone home — one lamp on, everything else
resting in ink. Luxury in the tailor's sense: precision and generous negative space, not gold
foil. Coral appears as if it were the one warm object left in a dim room — never a fill, never
twice with equal weight on the same slide.

## Visual language

- **Palette**: bg `radial-gradient(120% 100% at 50% 0%, #23202F 0%, #1E1B2E 45%, #16131F 100%)` —
  a room, not a flat fill. Primary text `#F3EFE8` warm off-white; muted text `#9891A3`/`#7C7488`/
  `#6E6680`; single accent `#E8705A`, used once per slide as a hairline, a label, or an underline —
  never a background, never a badge fill.
- **Fonts**: Lora 400/500, generous leading (1.35-1.5), centered, never bold, never at D2's
  aggressive scale — this system's power is in how little it needs to raise its voice. Nunito Sans
  600/700, small, +4-8% tracking, muted or coral, for the handful of functional marks.
- **Ground**: always the dark radial vignette. No photo. The darkness itself is the design; do not
  lighten it "for legibility" — legibility comes from generous type size and contrast against the
  warm off-white, not from a brighter background.

## How these templates work (read before generating)

1. Every template below ships as a complete markup block + the CSS it needs. Use it EXACTLY — only
   fill the `<!-- SLOT: ... -->` comments with real copy. Do not drop the hairline rule, the
   vignette gradient, or the centered composition to make a slide "simpler" or "punchier."
2. Coral spends itself exactly ONCE per slide (the hairline under the eyebrow, one glowing word, or
   the CTA button's outline) — the moment it appears twice with equal weight, the room's mood
   breaks. This is stricter than D2's one-per-slide rule: D3 tolerates zero decorative coral
   entirely more readily than it tolerates two instances.
3. Ratio of dark-to-light stays roughly 90/10 on every slide. Never introduce a light card, panel,
   or block — everything sits directly on the dark ground.
4. Centered composition throughout — this is the one direction in the pack that centers text by
   default rather than left-aligning it. Do not left-align a headline here; it breaks the "room"
   metaphor's symmetry.
5. The Two-Beat Pause template (below) is reserved for the single heaviest line in the deck — never
   use it more than once per carousel.

## Chrome mapping (contract elements re-skinned natively)

No HUD pills on a dark page — the required overlay elements fold into the existing quiet top row
and footer, styled to nearly vanish until they need to speak:

- `.progress-row` / `.progress-seg` / `.fill` → a barely-visible tick row under the top count/brand
  row, unfilled segments almost invisible (`rgba(255,255,255,.06)`), filled segments a soft coral
  glow — the one place coral is allowed to repeat across a slide, since it reads as a instrument
  gauge, not decoration.
- `.counter-chip` → the existing `.count` mark (small coral dot + "01 — 09").
- `.follow-tag` → **CTA slide only.** Replaces the top-right `.brand` label's text with "Tap to
  follow →", same tiny tracked-uppercase treatment, recolored from muted gray to coral — the single
  slide where the brand mark itself warms up.
- `.save-tag` → **Hook slide only.** A small muted label mirrored bottom-left of the footer,
  opposite `.next`, reading "Save this ↓" in the same `#6E6680` tone with a coral dot prefix.
- `.cliffhanger` → the existing footer `.next` line already IS the teaser copy; add the class
  there directly.
- swipe arrow → the existing outlined `.arrow` circle in the footer; add `class="swipe-arrow"`.

```css
.progress-row{position:absolute;top:52px;left:34px;right:34px;display:flex;gap:4px;z-index:20;}
.progress-seg{flex:1;height:2px;border-radius:1px;background:rgba(255,255,255,.06);overflow:hidden;}
.progress-seg .fill{height:100%;background:#E8705A;box-shadow:0 0 6px rgba(232,112,90,.5);}
.follow-tag{font-weight:700;font-size:9px;letter-spacing:.18em;color:#E8705A;text-transform:uppercase;}
.save-tag{font-weight:600;font-size:8.5px;letter-spacing:.06em;color:#6E6680;text-transform:uppercase;display:flex;align-items:center;gap:5px;}
.save-tag .dot{width:4px;height:4px;border-radius:50%;background:#E8705A;display:inline-block;}
```


## Rules

- Exactly one coral instance per slide (zero is acceptable on Two-Beat Pause and Quiet Practice's
  unlit items; two is never acceptable anywhere).
- Centered composition on every template except Quiet Practice, which left-aligns because a list
  reads better ragged than centered — this is the one sanctioned exception.
- Lora never bolder than 500 weight, never smaller than ~17px, always generously leaded.
- Body copy under 30 words per slide; hook headline 5-8 words hard cap.
- 90/10 dark-to-light ratio maintained on every slide — no light panels, cards, or fills.
