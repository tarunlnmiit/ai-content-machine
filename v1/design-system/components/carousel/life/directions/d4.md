# D4 — "Minutes of the Meeting" — LOCKED TEMPLATE PACK

Analog document. The most honest thing the narrator has ever admitted about their own silence
gets filed under the most bureaucratic, least emotional format imaginable — a carbon-copy minutes
sheet, typewriter monospace, form header, filing stamp. The mismatch between deadpan procedure and
real feeling is what makes it land; coral is rationed to the register an office would actually use
it in — a stamp, a redline, a filing tab — never mood lighting.

## Visual language

- **Palette**: paper `#F4EEE2` with faint mottled texture (radial gradients, never a heavy grunge
  filter) · ink `#2A2620` warm near-black · muted label tone `#8B8171` · accent `#E8705A` for
  stamp/redaction/margin-mark only.
- **Fonts**: **Courier Prime** (monospace) for all body copy and every structural label, uppercase,
  never justified, always ragged left. Lora Italic 600, small, appears ONCE per slide max — only
  for the single handwritten-style margin annotation. **Nunito Sans never appears anywhere in this
  direction** — it would break the artifact's period logic.
- **Ground**: always the mottled paper texture. No photo, no card, no rotation — this is a flat
  filed document, not a scrapbook page.

## How these templates work (read before generating)

1. Every template below ships as a complete markup block + the CSS it needs. Use it EXACTLY — only
   fill the `<!-- SLOT: ... -->` comments with real copy. Do not drop the form header, the hairline
   rules, or the filing stamp to make a slide "simpler."
2. Monospace does the heaviest lifting of any direction in this pack — body copy, labels, headers,
   ALL of it stays in Courier Prime. The one exception is the Lora-italic margin note, and it never
   appears more than once per slide.
3. Coral is rationed to exactly the register a real office memo would use it in: a rubber-stamp
   mark, a redline strike-through, or a margin-tab flag — never a fill, never a photo scrim, never
   more than one such mark per slide.
4. Structural labels ("ATTENDEES," "RE:," "MINUTE NO.") are uppercase monospace, same face as the
   body — a real form doesn't switch typefaces to announce its own sections.
5. The redaction bar in Redaction Reveal must keep the struck line fully legible underneath — the
   strike is emotional punctuation, not censorship; never actually black out the text.

## Chrome mapping (contract elements re-skinned natively)

No HUD pills on a filed document — every required overlay element becomes a piece of the form's
own bureaucratic apparatus, never a floating badge:

- `.progress-row` / `.progress-seg` / `.fill` → a small ledger of typewriter tick marks set into
  the header's bottom hairline, rendered as tiny filled/unfilled squares (`▪`/`▫`-style CSS blocks,
  not characters) so it reads as a page-count ledger, not a progress bar.
- `.counter-chip` → the existing `.hdr-row` "MINUTE NO. / 0X OF 09" value — add the class to that
  span directly. The counter value always lives in the MINUTE NO. field on the top-LEFT; it is a
  structured part of the form's header row, never positioned independently in the top-right.
- `.follow-tag` → **CTA slide only.** A second stamp beside `.stamp`, styled identically (bordered
  box, rotated -2deg, coral border+text) but reading "FOLLOW-UP REQUIRED" — the office's own way of
  saying "tap to follow."
- `.save-tag` → **Hook slide only.** A small stamp in the header's top-right corner, same bordered
  treatment as `.stamp` but reading "RETAIN COPY" — the filing-room equivalent of "save this." The
  counter never shares the top-right corner with the stamp — counter lives in the MINUTE NO. field.
- `.cliffhanger` → the existing footer `.next` line already IS the teaser copy; add the class
  there directly.
- swipe arrow → the arrow glyph already embedded inside `.next`'s text; wrap it in
  `<span class="swipe-arrow">→</span>`.

.progress-row{position:absolute;top:0;left:30px;right:30px;display:flex;gap:3px;justify-content:flex-end;z-index:20;}

## Rules

- Courier Prime everywhere except the Lora-italic margin note (max one per slide).
- Nunito Sans never appears anywhere in this direction.
- Coral limited to one stamp/redaction/margin-mark per slide — never a fill, never a background.
- Form header (MINUTE NO. / DATE / title) present on hook and every body slide; CTA slide swaps the
  DATE row for an ACTION/REQUIRED row.
- Body copy under 30 words per slide; hook headline 5-8 words hard cap, phrased as a procedural
  observation (third person, "attendee," not "I") — the first-person voice only ever appears inside
  the italic margin note or redaction.
