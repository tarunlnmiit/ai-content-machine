# Poetry Carousel — Direction D3: "After Hours" — LOCKED TEMPLATE PACK

Base philosophy: luxury is not gold everywhere, it is gold used exactly once, and only when it has
earned it. The entire world goes near-black; the gold is rationed to a single hairline, a single
dot, a single eyebrow label PER SLIDE. Restraint is the luxury signal — a museum wall label, a
first edition's frontispiece, printed once and never crowded. No drop shadows, no gradients beyond
one hairline's fade, no more than one type weight per composition.

## Visual language

- **Palette**: near-black `#15121E`, gold `#B89850` (the rationed content accent — hairline,
  eyebrow, dot), cream `#F3EEE2` / `#EDE7D9` for the hook/verse type itself, dimmed gray-lavender
  `#8B8598` for the secondary emphasis line, near-invisible ink `#3A3648` / `#4A4658` for the
  quietest chrome text.
- **Fonts**: Playfair Display italic carries every line of verse — one weight per composition,
  no bold/italic mixing within a single slide's content. `DM Sans` for the tiny handle/sig labels.
- **Ground**: flat near-black `#15121E`, no grain, no vignette — the flatness itself is the
  discipline (grain/vignette belongs to a different, rejected direction; do not reintroduce it).

## The gold-rationing rule (read before generating — this is the rule most likely to be broken)

Each slide's **content layer** gets exactly ONE gold-saturated mark: the eyebrow label OR the
hairline-and-dot pairing that opens/closes the verse — never both maxed out, never a second
independent gold flourish added "for balance." The **top hairline + counter numeral** are a single
recurring chrome signature that appears identically on every slide (like a running head on a book
page) — that repetition is permitted because it's one consistent device, not a new ornament each
time. All OTHER shared-chrome elements (follow-tag, save-tag, cliffhanger, swipe-arrow) render in
the muted gray-lavender/ink family, NOT gold — layering more saturated gold into the functional UI
chrome would dilute the "exactly once" promise the whole direction is built on.

## How these templates work (read before generating)

1. Every archetype ships as a complete markup block + CSS. Fill only the `<!-- SLOT: ... -->`
   comments. Do not add a second hairline, a drop shadow, a gradient beyond the one already
   specified, or a second type weight to a slide — the absence of those things is the craft.
2. The **shared overlay chrome** below is defined once — include it verbatim on every slide.
3. Center everything unless a template explicitly says otherwise — After Hours reads like a wall
   label, unhurried and centered, never off-kilter.

## HOOK TEMPLATE (mandatory) — Wall Label

A tracked-caps eyebrow, an enormous field of black, and the hook line set in italic serif at the
composition's optical center, closed with a single gold dot.

```html
<div class="hairline"></div>
<div class="eyebrow"><!-- SLOT: e.g. poem title in tracked caps --></div>
<div class="hook"><!-- SLOT: hook line, &le;8 words, use <br> for a 1-2 line break --></div>
<div class="dot"><span></span></div>
```

## BODY TEMPLATES

A hairline rule, four lines of verse alternating full cream and dimmed gray-lavender to mark
emphasis, ending on the same gold dot as a signature mark.

```html

  <div class="rule"></div>
  <div class="verse">
    <span class="dim"><!-- SLOT: dimmed line --></span><br>
    <!-- SLOT: full-emphasis line --><br>
    <!-- SLOT: full-emphasis line --><br>
    <span class="dim"><!-- SLOT: dimmed line --></span>
  </div>
  <div class="end"></div>
</div>
```

```css
.block{position:absolute;top:200px;left:46px;right:46px;text-align:center;}

```

### 5. Terminal Dot Only

Near-total black; a single word or fragment, small, low in the frame, closed by the gold dot — the
most extreme restraint archetype, reserved for a poem's single most devastating line.

Uses the same `.hairline`/`.eyebrow`/`.hook`/`.dot` CSS as the HOOK template. Render `.follow-tag`

## Rules

- **Hook headline** = the italic hook line, &le;8 words. Body slides carry stanza fragments — the
  generic &lt;30-word cap applies only to eyebrow/provenance chrome text, never to verse lines.
- One gold-saturated content mark per slide (see the gold-rationing rule above) — chrome elements
  stay in the muted gray-lavender/ink family, never full-saturation gold.
- No grain, no vignette, no drop shadow, no gradient beyond the top hairline's fade and the CTA
  hairline reuse — flatness is the discipline.
- Never run two of the extreme-restraint archetypes (Frontispiece, Terminal Dot Only) back to
  back; alternate them with the denser Wall-Label Stanza / Two-Line Held Breath / Provenance Line.
