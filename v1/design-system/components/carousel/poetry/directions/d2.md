# Poetry Carousel — Direction D2: "The Poem Is The Page" — LOCKED TEMPLATE PACK

Base philosophy: decoration is a confession the words weren't enough. No photography, no texture,
no framing device — the poem's own language, blown up in scale, IS the composition. Radical scale
contrast (not radical color) does the work illustration would do elsewhere. The single accent gold
is spent on exactly ONE word per slide, never more — everything else is disciplined black-on-cream
or fading gray-ink, so the eye has nowhere to rest except where the typography insists.

## Visual language

- **Palette**: near-black ink `#1E1B2E` (heaviest type), gold `#B89850` (the one accent word per
  slide, never more), fading grays `#6B6350` / `#9C927A` / `#B0A582` for secondary lines, cream
  ground `#F6F1E4`. Chrome/UI elements (progress, counter, follow-tag, save-tag, cliffhanger,
  swipe-arrow) stay in the fading-gray family — NEVER gold, since gold is rationed to one word in
  the content layer and chrome would dilute that discipline.
- **Fonts**: Playfair Display carries every word — its full weight range (300 italic whisper to
  900 roar) is the entire hierarchy mechanism. `DM Sans` only for the tiny chrome labels
  (counter/handle/tags), never for verse.
- **Ground**: flat `#F6F1E4`, no gradient, no grain, no card/frame. Type sits directly on the
  page — that bareness is the point.

## How these templates work (read before generating)

1. Every archetype ships as a complete markup block + CSS. Fill only the `<!-- SLOT: ... -->`
   comments. Do not add a card, border, texture, or icon to "help" a sparse slide — bareness is
   the craft, not an accident to be filled in.
2. Exactly ONE word or short phrase per slide gets the `.accent` gold treatment. If a slide's
   template shows an `.accent` slot, use it on the single most important word — never two, never
   zero on a slide that has one available.
3. Weight and size do the work color normally does elsewhere: pick which words in the SLOT content
   get the heaviest weight (900) vs. which fall to italic-light (300/400) — that decision ranks
   importance exactly the way `.hl` ranks importance in other niches' collage skins.
4. The **shared overlay chrome** below is defined once — include it verbatim on every slide,
   deliberately understated (small, gray, DM Sans) so it never competes with the typography.

## HOOK TEMPLATE (mandatory) — Escalating Triplet

Three words from the poem's emotional center, each on its own line at escalating scale, the final
word in gold.

```html
<div class="stage">
  <div class="word w1"><!-- SLOT: first word --></div>
  <div class="word w2"><!-- SLOT: second word/fragment --></div>
  <div class="word w3 accent"><!-- SLOT: third word — the ONE gold word --></div>
</div>
<div class="foot"><div class="rule"></div><div class="footlabel"><!-- SLOT: e.g. "Breath of Poetry &middot; [poem title]" --></div></div>
```

```css
body{background:#F6F1E4;}
.stage{position:absolute;top:64px;left:24px;right:16px;bottom:74px;display:flex;flex-direction:column;justify-content:center;}
.word{font-family:'Playfair Display',serif;font-style:italic;font-weight:900;color:#1E1B2E;line-height:0.86;letter-spacing:-0.01em;}
.w1,.w2{font-size:58px;}
.w3{font-size:76px;}
.word.accent{color:#B89850;}
.foot{position:absolute;bottom:26px;left:24px;right:24px;display:flex;align-items:center;gap:10px;}
.rule{flex:0 0 26px;height:1px;background:#8A6E30;}
.footlabel{font-size:8.5px;letter-spacing:0.14em;font-weight:700;color:#8A6E30;text-transform:uppercase;}
```

Do not add a fourth word, a border, or any texture — three lines of escalating type and the
gold-word payoff IS this archetype.

## BODY TEMPLATES

### 1. Typographic Waterfall (canonical)

A full stanza where one word is blown to near-poster scale as the stanza's true subject; the
surrounding lines shrink away from it in weight and size like an afterthought trailing to a corner.

```html
<div class="stage">
  <div class="l1"><!-- SLOT: line before the subject word --></div>
  <div class="l2"><!-- SLOT: the stanza's subject word/phrase --><br><span class="accent"><!-- SLOT: continuation, the ONE gold word --></span></div>
  <div class="l3"><!-- SLOT: line after --></div>
  <div class="l4"><!-- SLOT: line after --></div>
  <div class="l5"><!-- SLOT: trailing 1-2 line fragment, right-aligned corner --></div>
</div>
```

```css
.stage{position:absolute;top:70px;left:24px;right:20px;bottom:24px;}
.l1{font-family:'Playfair Display',serif;font-style:italic;font-weight:400;font-size:22px;color:#B0A582;}
.l2{font-family:'Playfair Display',serif;font-weight:900;font-size:64px;color:#1E1B2E;line-height:0.9;margin:4px 0 12px;letter-spacing:-0.01em;}
.l2 .accent{color:#B89850;}
.l3{font-family:'Playfair Display',serif;font-style:italic;font-size:19px;color:#6B6350;margin-top:6px;line-height:1.5;}
.l4{font-family:'Playfair Display',serif;font-style:italic;font-size:15px;color:#9C927A;margin-top:2px;}
.l5{font-family:'Playfair Display',serif;font-style:italic;font-size:15px;color:#9C927A;position:absolute;right:0;bottom:0;text-align:right;}
```

### 2. Single Word

One word or very short phrase, alone, filling most of the frame — the type-as-architecture read
taken to its extreme. No secondary lines at all.

```html
<div class="stage"><div class="mega"><!-- SLOT: one word or 2-word phrase --></div></div>
```

```css
.stage{position:absolute;top:0;left:20px;right:20px;bottom:0;display:flex;align-items:center;}
.mega{font-family:'Playfair Display',serif;font-weight:900;font-size:92px;line-height:0.88;color:#1E1B2E;letter-spacing:-0.02em;}
```

### 3. Weight Ladder

Four lines of the same stanza, each set at a different weight (900 → 700 → 400 → 300 italic) to
render the poem's own diminishing-emphasis argument as literal type weight.

```html
<div class="stage">
  <div class="r1"><!-- SLOT: line, heaviest --></div>
  <div class="r2"><!-- SLOT: line --></div>
  <div class="r3"><!-- SLOT: line --></div>
  <div class="r4"><!-- SLOT: line, lightest whisper --></div>
</div>
```

```css
.stage{position:absolute;top:80px;left:24px;right:24px;bottom:60px;display:flex;flex-direction:column;justify-content:space-between;}
.r1{font-family:'Playfair Display',serif;font-weight:900;font-size:38px;color:#1E1B2E;line-height:1.05;}
.r2{font-family:'Playfair Display',serif;font-weight:700;font-size:30px;color:#3A3428;line-height:1.1;}
.r3{font-family:'Playfair Display',serif;font-weight:400;font-size:24px;color:#6B6350;line-height:1.2;}
.r4{font-family:'Playfair Display',serif;font-style:italic;font-weight:300;font-size:19px;color:#9C927A;line-height:1.3;}
```

### 4. Enjambment Cascade

A single sentence broken across a staircase of line breaks, each fragment indented further than
the last, tracing the poem's own enjambment down the page. The one gold word marks the sentence's
turn.

```html
<div class="stage">
  <div class="step s1"><!-- SLOT: fragment 1 --></div>
  <div class="step s2"><!-- SLOT: fragment 2 --></div>
  <div class="step s3"><!-- SLOT: fragment 3, wrap the turn word in <span class="accent">...</span> --></div>
  <div class="step s4"><!-- SLOT: fragment 4, closing --></div>
</div>
```

```css
.stage{position:absolute;top:76px;left:24px;right:20px;bottom:40px;}
.step{font-family:'Playfair Display',serif;font-weight:600;font-size:26px;color:#1E1B2E;line-height:1.28;margin-bottom:6px;}
.s2{margin-left:24px;color:#3A3428;}
.s3{margin-left:48px;font-style:italic;}
.s3 .accent{color:#B89850;font-weight:900;}
.s4{margin-left:72px;font-size:20px;color:#6B6350;}
```

### 5. Margin Whisper

Almost the entire frame left as flat cream void; one small italic line pinned low in a corner, set
far smaller than every other archetype in this pack — the restraint extreme that makes the other
four read as loud by comparison.

```html
<div class="whisper"><!-- SLOT: one short line --></div>
```

```css
body{background:#F6F1E4;}

```

## CTA TEMPLATE (derived from hook — same Escalating Triplet register)

```html
<div class="stage">
  <div class="word w1"><!-- SLOT: e.g. "Read" --></div>
  <div class="word w2"><!-- SLOT: e.g. "the whole" --></div>
  <div class="word w3 accent"><!-- SLOT: e.g. "thing." — the ONE gold word --></div>
</div>
<div class="foot"><div class="rule"></div><div class="footlabel"><!-- SLOT: comment-keyword CTA, e.g. "Comment POEM — full text below" --></div></div>
```

Uses the same `.stage`/`.word`/`.foot` CSS as the HOOK template. Render `.follow-tag` on this
slide (no `.save-tag`, no `.swipe-arrow`, no `.cliffhanger`).

## Rules

- **Hook headline** = the three-word escalation, &le;8 words total across all three lines. Body
  slides carry full stanzas — the generic &lt;30-word cap applies only to `.footlabel`/chrome
  text, never to verse lines, which flow at their natural length.
- Exactly one `.accent` gold mark per slide, never more — this is the hardest rule in this pack to
  break by accident (do not gold two words "for balance").
- No card, border, gradient, icon, or texture anywhere in this direction — flat cream, flat ink,
  one gold word. If a slide feels too bare, that means it's working; do not add ornament to fix it.
- Alternate dense archetypes (Typographic Waterfall, Weight Ladder, Enjambment Cascade) with the
  bare extremes (Single Word, Margin Whisper) so the deck breathes; never run two bare extremes
  back to back.
