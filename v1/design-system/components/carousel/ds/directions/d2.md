# D2 — The Verdict — LOCKED TEMPLATE PACK

Typography-first editorial: near-zero decoration, all scale. A high-contrast display serif
(Fraunces) carries the entire visual event against the brand's own Space Grotesk, demoted to pure
utility type — eyebrows, file numbers, footer marginalia. One thin blue rule is the only color
accent permitted. No cards, no rotation, no texture. When nothing can hide a weak line, every line
has to earn its size — that pressure is what makes the system read as edited, not assembled.

## Visual language

- **Palette**: page `#FAF9F5`, ink `#1E1B2E`, secondary ink `#4A4658`, marginalia `#9A968A`,
  hairline `#E2DFD5`, the single accent `#6B8FA8` (rule only), eyebrow color `#3D5F75`.
- **Fonts**: 'Fraunces', serif (headline + dek, italic for the dek) — the only typeface with
  character in the system; 'Space Grotesk', sans-serif (everything else: eyebrow, labels, footer)
  kept small and deliberately unglamorous next to the serif's weight.
- **Texture**: none, ever. No paper grain, no doodles, no shadow beyond what a rule needs. Space
  itself is the material — margins generous to the point of feeling expensive.

## Chrome mapping (exporter contract, re-skinned into the manuscript page)

The circular ink-filled marker in the top-left corner IS the counter badge — not a chip borrowed
from an app, a page number in a numbered private notebook, which is the only case in which a
number belongs on the page at all. `.follow-tag`, swipe arrow, `.save-tag`, and `.cliffhanger`
stay at their mandated corners but are drawn as quiet marginalia — no pill backgrounds, no
borders — so they read as footnotes, not UI. `.progress-row`/`.progress-seg`/`.fill` is a single
hairline rule at the very top of the page, the thinnest possible progress indicator, styled to
look like a printer's registration mark rather than an app loading bar.

## Rules

- Never add a card, shadow, texture, or rotation anywhere in this direction — type and negative
  space are the only material. Adding decoration here is the single failure mode that produced
  the client's "fractional improvement" complaint about the retired system.
- Never omit the standalone `.rule` beneath a headline — an underlined word inside the headline is
  optional; the rule itself is not.
- Hook headline: 5-8 words, hard cap, lives only in `.headline` on the hook slide.
- Body copy per slide: under 30 words total.
- Never use the same body template on two adjacent slides.
- The circular `.marker` number must increment sequentially and match the slide's true position in
  the deck — it is the page's only numbering device, so it has to be correct.
