# 01 — Hook / Angle Library

8 archetypes, ranked by frequency + performance in the saved set. These are **angle patterns** — use them for blog titles, YouTube titles, reel hooks, and carousel covers, not just reels. Each entry: pattern → real examples → performance note.

> Sibling of `twitter_hook_patterns.json`. Keep this markdown for humans/agents; derive a JSON sample table later if a script needs to pick programmatically.

### 1. Equation hook  — `[Tool] + [Tool] = [outcome]`
Most common pattern in the set. Logos + a result, instantly legible muted.
- "Claude + Instagram = Cheat Code"
- "Claude x Higgsfield = $10K/month"
- "Claude + Metricool = every social platform on autopilot"
- Performance: the *tool+tool* versions (real integrations) outperform the *tool+income* versions. Use the integration framing.

### 2. Number / Result hook — lead with a specific outcome
- "His Openclaw agent made him $80,000" (32.8K likes)
- "30,000 followers and 2.5M views in 36 days"
- Performance: huge reach, but income numbers attract the wrong crowd. Prefer a result you can show (speed, output volume, a built thing) over a dollar figure.

### 3. Numbered listicle — "N things/ways/secrets"
- "5 secret Claude codes" (20.9K), "4 things Claude can do that'll make you feel dumb", "10 ways to cut Claude token usage 75%"
- Performance: high saves; ideal for carousels and YouTube chapters.

### 4. Secret / News hook — curiosity gap, often news-anchor framing
- "BREAKING: Claude has a secret mode called 'Wealth Protocol'" (17.9K)
- "A Reddit user gaslit Claude and it gave crazy results"
- Performance: strong top-of-funnel; land it honestly (show the real result) or it ages into a hype-roast (see guardrail).

### 5. Free-vs-Paid comparison — two-column / two-person split
- "FREE vs PAID AI Tools 2026" (26K, ~1.7K shares)
- Performance: outsized shares/saves. Excellent carousel format.

### 6. Accessibility hook — collapse the skill barrier
- "Even a 16 year old can do this", "Even a 12 year old can do it"
- Performance: broadens reach; pair with a genuinely simple demo or it rings hollow.

### 7. Roadmap / resource-dump — aspirational reference
- "If I had one weekend to master Claude, I'd start here:" + linked list
- "Stop bookmarking 50 guides — here are 15 free ones"
- Performance: highest save intent; perfect for a carousel or a blog pillar post with a lead magnet.

### 8. One-AI-replaces-a-team
- Claude as "creative / copywriter / competitor spy / researcher / video editor"
- Performance: strong for build/teach hybrid; maps naturally to a YouTube segment per "role".

## How to use this across formats
- **Blog/YouTube title:** pick the archetype that fits the post's core promise (roadmap for pillar posts, secret/number for tactical ones).
- **Reel/clip hook:** the first 3s must be the archetype in big text.
- **Carousel cover:** archetypes 3, 5, 7 are the carousel-native ones.
- Test 2–3 hook variants per piece; keep the winner; log it in `03_swipe_file.md`.
