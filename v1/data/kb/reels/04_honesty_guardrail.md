# 04 — Honesty Guardrail

Non-negotiable QA gate. Applies at the **blog stage** (so it propagates to every derivative) and again at final review of each format. The winner outperformed *because* it under-promised and over-showed.

## The rules
1. **State what the tool actually does.** Never claim what you can't put on screen ("auto-applies" when it only drafts).
2. **Borrow the hook mechanics, not the income claims.** Equation/number/secret/listicle hooks are fine; "$10K/month" headlines are not, for this brand.
3. **Every claim needs visible proof.** A result you can show (speed, output volume, a built thing) beats a dollar figure.
4. **Real, free artifacts win.** If you reference a repo/skill, it must exist and be linkable.

## Why — the evidence
- **Income-bait draws the wrong crowd.** the_eppisai (₹1L/month) and thegulerana ($10K month + $47 course) fill comments with "share pls / hi" — shortcut-seekers, not your audience.
- **Over-hype gets publicly roasted.** hasantoxr's "Claude Code runs 100% locally" reel has a top comment (81 likes): "I hate hype posts like these," calling out inaccuracy. That's the scam reflex to avoid.
- **Honesty is rewarded.** rubenhassid's roadmap reel has a top comment praising the "most honest" guide on the list. the_eppisai's own honest line — "Month 1: ₹0. You're learning… it compounds" — is the right instinct.

## Pass/fail checklist (run before publishing any format)
- [ ] Every claim in the script is demonstrable on screen.
- [ ] No dollar/income figure used as the headline hook.
- [ ] Any referenced repo/skill/tool exists and is linkable.
- [ ] "Free / open / local" used only where literally true.
- [ ] Reads as confident and specific, not hyped. If a skeptical engineer would comment "this is wrong," fix it first.
