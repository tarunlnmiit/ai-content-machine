## The Comment→DM CTA Model (non-negotiable on reels)

Every high-performing post uses a single keyword CTA in the caption:
- "Comment **READY** and I'll send you..."
- "Comment **CLAUDE** and I'll send you..."
- "Comment **skill** and I'll send you the spy skill + guide"
- "Comment **Content** and I'll send you the full guide"
- "Comment **Connect** and I'll send you the full guide"
- "Comment **skills** for the full install guide"
- "Comment **Tool** and I'll send you a dm"

**The formula:** One word. All caps or title case. Promise something specific you'll DM.
The word doubles as a signal of intent (people who comment "skill" want to learn skills).

For Tarun's DS niche: use `free_tool_ds` project keywords — `FLOW`, `SYSTEM`, `TOOL`, `CLAUDE`
For Life niche: use `SYSTEM`, `GUIDE`, `HABIT`
For Poetry: not applicable (different audience, different CTA model)

## Hook Structures That Work (steal these patterns)

### Pattern 1 — Revelation hook (mavgpt's highest performer)
```
"You can now [do something that sounds impossible/new]."
→ explain what changed
→ show how it works in numbered steps
→ CTA
```
Example: "You can now connect Claude directly to every single social media platform."

### Pattern 2 — Theft hook (incomewithjoe, milamarksonofficial)
```
"STEAL THESE [THING] 👇"
→ numbered list of the things
→ credibility line ("these are the same [things] I used to [specific result]")
→ CTA
```
Example: "STEAL THESE PROMPTS 👇 These are the exact prompts I use to turn ideas into views."

### Pattern 3 — Urgency/save hook (katecore.ai)
```
"You need to SAVE this right now ❗️"
→ resource list / carousel
→ follow CTA
```
Best for: resource carousels, tool lists, reference content.

### Pattern 4 — Step-by-step setup hook (mavgpt's formula)
```
"Here's how to set it up in 30 seconds:"
1. [step]
2. [step]
3. [step]
→ outcome with specific number ("50 UGC ads", "under a minute")
→ Comment→DM CTA
```
Specificity drives credibility. Never say "a few minutes" — say "30 seconds" or "3 steps."

### Pattern 5 — Sophisticated prompt frame (miroslava.smith)
```
"Act as a [specific expert role] who [specific constraint/expertise]."
→ 5 named prompts, each with a clear function
→ Link in bio CTA
```
Best for: carousel content targeting serious creators, not mass-market.

## Reel Script Structure (mavgpt formula — highest performers)

```
[0–2s]  Hook line — revelation or theft pattern. One sentence.
[2–5s]  Stakes — what this changes / why it matters now
[5–20s] How it works — numbered steps, shown on screen
[20–25s] Result — specific number or outcome ("did X in Y time")
[25–30s] CTA — "Comment [KEYWORD] and I'll send you the full guide"
```

Never explain more than 3–4 steps in a reel. If it needs more, it's a carousel.

## Caption Formula (from top performers)

```
[Hook line — same as first 2s of reel, or stronger]

[2–3 lines of context — what problem this solves]

[Numbered steps OR bullet list of what they get]

[Credibility line — specific result or social proof]

[Comment→DM CTA — bold, single keyword]

[Optional: follow prompt]
[Hashtags — 3–5 max, niche-specific]
```

mavgpt's caption style: very clean, minimal hashtags (3–5), numbered steps in body,
CTA at top AND referenced again in the body. No fluff.
