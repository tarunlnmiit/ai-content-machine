02
Diagnose before you calculate

Check and Convert Types

  • type(x) tells you what Python thinks
  • int(), float(), str() convert types
  • Always check before calculating
First diagnostic habit.
Run type() on every column before you touch the data.
type_check.py
x = "42" print(type(x)) # <class 'str'> x_int = int(x) print(type(x_int)) # <class 'int'> print(x_int + 1) # 43 # Diagnose before you calculate ages = ["28", "35", "42"] print(type(ages[0])) # <class 'str'> ages_clean = [int(a) for a in ages] print(sum(ages_clean)) # 105
03
The fundamental collection

Lists: Ordered Sequences

  • Index from 0, slice with [start:end]
  • append() adds to the end
  • Comprehensions: filter in one line
Same result, two ways
high = []
for s in scores:
  if s > 85: high.append(s)
↓
high = [s for s in scores if s > 85]
lists.py
scores = [72, 88, 91, 64, 95, 83] # Indexing print(scores[0]) # 72 print(scores[-1]) # 83 # Slicing (end excluded) print(scores[1:4]) # [88, 91, 64] # List comprehension high = [s for s in scores if s > 85] print(high) # [88, 91, 95]

The natural shape of a dataset

Dictionaries: Named Records

dicts.py
employee = {"name": "Tarun", "age": 28} # Safe access — no KeyError dept = employee.get("dept", "Unknown") # List of dicts — dataset shape employees = [ {"name": "Tarun", "salary": 95000}, {"name": "Priya", "salary": 87000}, {"name": "Carlos", "salary": 102000}, ] total = sum(e["salary"] for e in employees) print(total) # 284000
  • Key-value pairs — one record per dict
  • .get() for safe access
  • List of dicts = natural dataset shape

05
Reusable, testable, single-source-of-truth

Functions: Write Once, Trust Forever

functions.py
def calculate_average(values): if not values: return 0 return sum(values) / len(values) scores = [72, 88, 91, 64, 95] print(calculate_average(scores)) # 82.0 import statistics def is_outlier(val, data, threshold=2.0): mean = calculate_average(data) std = statistics.stdev(data) return abs(val - mean) > threshold * std print(is_outlier(150, scores)) # True print(is_outlier(88, scores)) # False
  • def — reusable, testable
  • Default args: threshold=2.0
  • One function replaces 3 notebook copies
