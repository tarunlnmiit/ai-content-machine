Clean + Aggregate

Fix the mess.
Find the pattern.

1
Drop nulls or fill them
df.dropna()  ·  df.fillna(0)
2
Fix data types
df['date'] = pd.to_datetime(df['date'])
3
Remove duplicates
df.drop_duplicates()
4
Group and aggregate
df.groupby('city')['sales'].sum()
