The Problem

Default matplotlib is
lying about your work

🔲
Gray background — signals "rough draft" to every stakeholder
🔡
Tiny fonts — designed for 800×600 monitors. Illegible in any deck
📦
Cluttered box borders — top + right spines add zero information
📊
No narrative — data without visual intent is just a number dump

"The first comments weren't about the analysis. They were about how difficult the charts were to read."

The Mental Model
seaborn
+ matplotlib
= 95% of what you'll ever need
1
seaborn — high-level plots, beautiful defaults, 3–5 lines per chart
2
matplotlib — low-level control for every pixel seaborn can't reach
3
seaborn is built ON TOP of matplotlib — layers, not competitors

Use seaborn for the 80%. matplotlib for the last 20%.

Setup Block

Copy this to the top of every notebook. Run once.

import pandas as pd import matplotlib.pyplot as plt import seaborn as sns # Global style baseline sns.set_theme( style="whitegrid", palette="muted", font_scale=1.2 ) plt.rcParams.update({ "figure.dpi": 150, "axes.spines.top": False, "axes.spines.right": False, })
✓
whitegrid — white bg + light gridlines. Instant upgrade
✓
font_scale 1.2 — readable in any slide deck or Medium image
✓
Remove spines — top/right borders carry zero data. Kill them

5 Essential Plot Types

These 5 cover 90% of all EDA you'll ever do

Distribution
sns.histplot
Shape + skew of any column
Relationship
sns.scatterplot
2 vars + hue = 3rd dim
Categories
sns.barplot
CI error bars automatic
Correlation
sns.heatmap
Full matrix, annotated
Grouped Distribution
sns.boxplot — spread + outliers across categories

Titanic: 1st class 63% survival · 3rd class <25%. One barplot. The story lands instantly.

4 Details That Separate Good Charts from Bad
1
Units on every axis
"Fare" → "Fare (£)" → "Fare in GBP, 1912"
2
Explicit color assignment, never random
palette={0: "salmon", 1: "steelblue"}
3
Zero-baseline on bar charts
plt.ylim(0, 1) — not enforced automatically
4
Save at 300 DPI, not 72
fig.savefig("out.png", dpi=300, bbox_inches="tight")

These require zero design skill. Just intention. That's the entire gap.
