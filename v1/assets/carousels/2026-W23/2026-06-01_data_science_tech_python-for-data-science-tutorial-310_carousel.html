Speed

A Python list can store any type — integers, strings, booleans, mixed. That flexibility forces pointer-chasing in memory and prevents the CPU optimisations that make numeric work fast.

When data scientists say "Python is fast", they mean NumPy Python — vectorised operations running in compiled C code, not the loops you've been writing.

The Solution

NumPy: describe
operations on
entire arrays at once.

🔢
Contiguous memory
All elements same type → stored side-by-side → no pointer overhead
⚡
Compiled C & Fortran core
Python syntax, C-speed execution — 50–200× faster than loops
📡
Broadcasting
Apply operations across whole arrays — zero Python loops needed

Vectorized Operations

Stop looping.
Start describing.

import numpy as np scores = np.array([85, 92, 78, 95, 88]) # Arithmetic — every element at once scores + 5 # [90 97 83 100 93] scores ** 2 # [7225 8464 6084 ...] # Boolean indexing — filter without loops above_90 = scores > 90 # [False True False True False] scores[scores > 90] # [92 95]
Why this matters: Pandas df[df["col"] > val] is exactly this pattern. Understanding boolean indexing now means Pandas won't feel like magic later.
Outlier Detection in 6 Lines

Aggregations → IQR → filter

1
Compute quartiles
np.percentile(data, 25) # Q1
np.percentile(data, 75) # Q3
2
Calculate IQR & fences
iqr = q75 - q25
upper = q75 + 1.5 * iqr
lower = q25 - 1.5 * iqr
3
Filter with boolean indexing
data[(data > upper) | (data < lower)]
4
Axis for 2D arrays
data.mean(axis=0) # per column
data.mean(axis=1) # per row
