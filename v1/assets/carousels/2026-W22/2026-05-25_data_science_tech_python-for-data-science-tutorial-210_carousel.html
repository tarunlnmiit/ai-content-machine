The silent bug
Your CSV column loads as strings, not numbers.
raw_age = "28"  # from a CSV
print(raw_age + "10")
>>> "2810"  # NOT 38
No warning. No traceback. Just a number that's plausible enough to fool you — and anyone reading your report.

Check before you trust it
Four types run every pipeline you'll build.
int28, 2024
float85000.50
str"analyst"
boolTrue / False
Rule: type() tells you what you're holding. int(), float(), str() convert it before you compute.

Trips up every beginner, week one
scores[1:3] never gives you what you think.
scores = [85, 92, 78, 95, 88]
scores[1:3]
>>> [92, 78]  # index 1, 2 — NOT 3
Slicing is exclusive on the end. Comprehensions filter and transform in one line: [s/100 for s in scores if s>85].

Write it once, reuse it forever
A function that flags outliers in 4 lines.
def is_outlier(v, mean, threshold=2.0):
  return abs(v-mean)/mean > threshold/10
outliers = [s for s in scores if is_outlier(s, mean)]
>>> [78, 150]
No libraries. Default arguments let you override the threshold per call — same function, every dataset.
