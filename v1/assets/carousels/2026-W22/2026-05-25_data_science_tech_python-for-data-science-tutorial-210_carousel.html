The Silent Bug
02 / 07

Python has no idea you wanted a number.

Your CSV "age" column — loaded as strings
"28" + "35" + "42"
↓ concatenates, not adds
"283542"
⚠ No error · No warning · Wrong answer

A number plausible enough to fool you — and anyone reading your report. The bug only surfaces when someone questions your numbers, or when data changes six months later.

The Fix
03 / 07

Types encode intention. Check what Python is actually holding.

# Step 1 — inspect the type
type(column[0])  # <class 'str'>

# Step 2 — convert explicitly
ages = [int(x) for x in column]

# Step 3 — now sum is correct
sum(ages)  # → 105, not "283542"

Python is dynamically typed — it infers types from values. You need to verify the inference matches your intent. Four types cover 90% of what you'll hold in a variable.

Lists & Dicts
05 / 07

Sequences and records

Lists = ordered sequences. Dicts = labeled records. Together they model every dataset.

# List — filter via comprehension
scores = [72, 88, 91, 65, 95]
high = [s for s in scores if s > 85]
# → [88, 91, 95]

# Dict — safe key access
row = {"name": "Alice", "salary": 95000}
row.get("dept", "Unknown") # no KeyError

# Aggregate across list-of-dicts
total = sum(e["salary"] for e in employees)
