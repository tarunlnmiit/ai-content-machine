The scare that almost shipped

"Remove invalid dates" → it deleted 4,000 real signups.

A null signup_date meant organic, non-funnel — not broken data. The agent ran, reported success, and the number looked plausible enough to almost ship.

# what it did — plausible, and wrong:
df = df[df["signup_date"].notna()]

# the fix is a judgment call:
df["signup_channel"] = df["signup_date"].isna().map(
  {True: "organic", False: "paid_funnel"}
