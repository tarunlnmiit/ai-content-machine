# Reel Script v2 — "I stopped writing bad prompts" (Prompt Anatomy — Jobhunt Framework)

**Niche:** Data Science / Tech · **Format:** talking-head + screen-record proof (before/after)
**Source blog:** `content/blogs/2026-W25/2026-06-16_data_science_tech_ai-prompt-anatomy-travel.md`
**Slug:** `2026-06-16_data_science_tech_ai-prompt-anatomy-travel`
**Length target:** 38–45s (trims to 30s) · **Pace:** 140–160 wpm
**Formula:** `data/kb/viral_reel_formula.md` (5 beats) — same structure as the jobhunt reel

> **Why v1 underperformed vs jobhunt reel:**
> v1 was educational ("here's a technique"). Jobhunt was product-shaped ("here's a free thing I built you can have").
> v1 used Paris travel as the proof — wrong niche for a DS audience, weak save motivation.
> v1 DM payload = a Paris-specific prompt nobody else needs.
> v2 fixes: universal DS pain point, before/after proof, reusable template as DM payload.

> Non-negotiables: captions burned in (85% watch muted), cut on every sentence, hard cut at 0s,
> trending audio low under voice, end on the output — not on "bye" (loop bait).

## THUMBNAIL TEXT (burned in over face — this IS the hook before they press play)

The text must state the outcome, not the topic. Test these three:

**Lead:** `Most data scientists use ChatGPT like beginners 😳`
**Alt 1:** `I tested 100 data prompts. This 5-part structure won 😳`
**Alt 2:** `The prompt structure that changed how I use AI for data 🤯`

Rule: thumbnail text + first spoken words must match. If thumbnail says "most data scientists
use ChatGPT like beginners" — your first spoken words echo that exact claim.

Series opportunity: brand this as **"Prompt Anatomy pt1"** in the thumbnail text — sets up pt2,
pt3 as easy follow-up content. Add "pt1" small in the corner.

## HOOK — 0–3s (record 5×, keep the winner)

Hard cut. Face to camera. Big burned-in caption. Test all three, ship the strongest.

**Lead — Contrarian Mirror (same pattern as jobhunt hook):**
> "Most data scientists spend 3 hours getting garbage from ChatGPT. Then they blame the model. The model's fine."
*Caption:* `THE MODEL'S FINE.`

**Alt 1 — Bold Declaration (authority-forward):**
> "I've reviewed hundreds of AI outputs from data scientists. 90% have the same problem — and it's not the model."
*Caption:* `90% HAVE THE SAME PROBLEM.`

**Alt 2 — Social Proof Inversion (observed, not personal):**
> "Every junior data scientist I mentor asks me why ChatGPT gives them useless output. I show them this."
*Caption:* `WHY YOU GET USELESS OUTPUT.`

**Hook rule:** one of these MUST start with a specific number or a named observation — same as
`"I built a FREE AI agent that hunts jobs while I sleep."` worked because it named the
exact thing. "Until last week / including me" wording is banned — it undermines 10 years of
credibility. Frame from expertise ("I've seen", "I teach", "I reviewed") not personal ignorance.

## PROBLEM — 3–8s

Face to camera. Quick. Name the exact pain.

> "You type: 'Analyse this dataset and give me insights.'
> You get: 5 bullet points that tell you nothing you didn't already know.
> The model isn't broken. You asked like a beginner."

*Caption:* `YOU ASKED LIKE A BEGINNER.`

**Why this works (jobhunt parallel):** The jobhunt problem was "job hunting is a full-time job."
This problem is "bad prompts waste hours of your work day." Both are visceral, specific, and
the audience nods before the fix arrives.

## REVEAL + PROOF — 8–28s

VO over **screen-record B-roll**. The proof must be VISUAL — show two actual outputs side by side.
This is the structural requirement the jobhunt reel met (showing the Telegram ping + the scored
shortlist) that v1 did NOT meet (v1 just showed one nice output, no before/after contrast).

**Shot sequence — build the before/after on screen:**

> "So I gave the model a job. Same dataset. 5-part prompt."

*Cut to screen — show the bad prompt first:*
- 3a: `"Analyse this dataset and give me insights"` → show the generic output (bland bullets).
  *Caption:* `BEFORE`

*Cut to building the structured prompt line by line:*
- 3b: `ROLE — expert analyst, not assistant.` *Caption:* `1 ROLE`
- 3c: `TASK — three non-obvious patterns, with the column name and p-value.` *Caption:* `2 TASK`
- 3d: `EXCLUDE — no summary stats I can see myself.` *Caption:* `3 EXCLUDE`
- 3e: `FORMAT — a table. Flag if any finding needs more data.` *Caption:* `4 FORMAT`
- 3f: `VERIFY — cite the row range for each finding.` *Caption:* `5 VERIFY`

*Cut to the structured output:*
- 3g: The output table renders — specific patterns, column names, p-values, flagged uncertainty.
  Zoom the rows. *Caption:* `AFTER`

> "Same model. Same dataset. Completely different output."

to one dataset or one travel trip.

## DM payload — universal 5-part prompt template

This is the key fix from v1. v1 gave people a Paris-specific prompt nobody else needs.
This payload is universal — the receiver can use it on any task immediately.

```
ROLE: You are [specific expert title — not "an AI assistant"].
Example: "You are a senior data analyst with 10 years in [domain]."

TASK: [one specific outcome + measurable constraint]
Example: "Find three non-obvious patterns in this dataset. Include the column name,
direction of the relationship, and a p-value or confidence note."

EXCLUDE: [common bad outputs to block]
Example: "Do not return summary statistics I can already see. Do not make general
observations without citing data."

FORMAT: [exact structure — table/numbered list/code block]
Example: "Return a markdown table: Pattern | Column(s) | Evidence | Confidence |
Flag if more data needed."

VERIFY: [cross-check requirement]
Example: "Cite the row range or data subset for each finding. If a finding is
uncertain, say so explicitly — don't smooth it over."
```

Copy this. Replace the examples with your task. The model will stop hallucinating.

## Caption (post this verbatim — the caption IS the product)

The full template goes IN the caption. People save the post to screenshot it.
The DM sends a formatted version; the caption body has it too.

```
Comment "PROMPT" and I'll send you the full fill-in-blank version 👆

Most data scientists write prompts like beginners. Here's what changes everything.

The 5-part prompt structure:

1. ROLE — "You are a senior data analyst with 10 years in [domain]."
   (Not "You are an AI assistant." Be specific.)

2. TASK — One outcome + measurable constraint.
   "Find three non-obvious patterns in this dataset. Include column name, direction, and p-value."

3. EXCLUDE — Block the garbage.
   "No summary stats I can already see. No general observations without data."

4. FORMAT — Tell it exactly what to return.
   "Markdown table: Pattern | Column(s) | Evidence | Confidence | Flag if uncertain"

5. VERIFY — Force a cross-check.
   "Cite the row range for each finding. If uncertain, say so explicitly."

Same model. Same dataset. Completely different output.

#datascience #ai #chatgpt #python #dataanalyst
```

## What changed from v1 (the jobhunt framework transplant)

| Element | v1 (underperformed) | v2 (jobhunt framework) |
|---------|--------------------|-----------------------|
| **Framing** | "Here's a technique" (educational) | "Here's a template you can have" (product-shaped) |
| **Pain point** | Generic "better prompts" | Specific: 3 hours wasted / 6 months of garbage output |
| **Niche fit** | Paris travel (mismatch for DS audience) | Data analysis (exact audience pain) |
| **Proof** | One nice output | Before/after side-by-side (same input, different prompt) |
| **DM payload** | Paris-specific prompt (1 use) | Universal 5-part template (reuse on any task) |
| **Save motivation** | Low — why save a travel prompt? | High — everyone wants to save a reusable template |
| **Loop bait** | Ended on face | Ends on the AFTER output table |

- [ ] Bad prompt output captured on screen (generic, blah bullets)
- [ ] Structured prompt built line by line on screen (5 parts, sequential)
- [ ] AFTER output captured (table, specific, zoomed for mobile)
- [ ] Before/after cut present in beat 3 — this is non-negotiable
- [ ] 5 beats present, ≤45s, captions burned in
- [ ] Ends on AFTER output table (loop bait), not on face
- [ ] CTA = one keyword `PROMPT`; comment→DM armed (SuperProfile / CreatorFlow)
- [ ] DM payload = universal template (not Paris-specific)
- [ ] UTM base swapped to live blog URL on publish
