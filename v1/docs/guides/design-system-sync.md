# Design-system mirror (`v1/design-system/`)

Read-only preview bundle that mirrors the repo's three token systems into 26
self-contained HTML cards, generated by `v1/scripts/generate_design_system.py`
and synced to a single claude.ai/design project named **"Breath Network"**.
Created 2026-07-10.

## What it is

Every emitted file starts with `<!-- @dsCard group="..." -->` so the Design
System pane auto-indexes it. 26 cards across 4 groups:

- **docs** (2) — `index.html` (overview), `resync.html` (this procedure, HTML form)
- **foundations** (9) — brand-core × 4 (index/ds/life/poetry), video × 4
  (ds/life/poetry/layout-catalogue), worksheet × 1
- **components** (15) — carousel archetypes × 3, carousel samples × 2, worksheet
  shell + samples × 3, social × 3, deck × 1, thumbnail × 3

## The three token systems

| System | Source | Consumers |
|---|---|---|
| A — Brand kit | `v1/data/brand/brand_kit.yaml` | carousel, social images, slide deck, script images, thumbnail |
| B — Video look bibles | `v1/data/kb/design/*_design.md` | HyperFrames / Remotion beat builders |
| C — Worksheet shell | `v1/scripts/templates/worksheet_shell.html` | `generate_worksheet_html.py` → A4 PDF |

## THE RULE

**Mirror only.** Never edit files in the claude.ai/design project directly —
edit the repo sources listed above and re-run the generator. The palettes
across A/B/C are **intentionally divergent** — they are visually adjacent but
numerically unrelated on purpose. Do not reconcile them.

**Known drift (documented, intentional):** `generate_thumbnail.py::_CANVA_NICHE_CFG`
hand-mirrors the brand kit and adds off-palette pop colors — labeled directly
on the Thumbnail cards, not treated as a bug.

**Known gaps:** Poetry niche has no recent real carousel artifact, so it only
has an archetype card. Worksheets are DS & Life only by design (not a third
niche).

## Re-sync steps

```bash
python3 v1/scripts/generate_design_system.py
git diff --name-only v1/design-system/     # changed files only
```

Then run `/design-sync` **incrementally**: `finalize_plan` + `write_files` for
only the changed paths reported by `git diff` (deletes for removed files).
Never wholesale-replace the project — that discards edit history and is slow
for no benefit, since the generator's output is deterministic per source file.

## Watch-outs

- Keep every card file well under 256KiB — no base64-embedded images. Pinned
  sample cards copy real HTML artifacts (carousel/worksheet exports); if a
  future pin is image-heavy, strip embedded images before pinning it.
- Google Fonts (`fonts.googleapis.com`) may be CSP-blocked in the claude.ai/design
  preview. Every card falls back to generic font stacks, so this degrades
  gracefully — it is not a rendering bug.
- The bundle is a deterministic full rewrite of `v1/design-system/` each run
  (`shutil.rmtree` + regenerate) — always diff before syncing rather than
  assuming which cards actually changed.
